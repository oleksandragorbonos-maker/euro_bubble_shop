# eurobubbleshop: сторінка «Холодне відновлення Triology»

Сторінка товару з кнопкою «Зробити замовлення».
Замовлення приходять у вашу **Telegram-групу**, а копія зберігається в **Google-таблиці**.
Усе працює безкоштовно.

## Що де лежить

| Файл | Що в ньому |
|---|---|
| `index.html` | Текст сторінки: назва, ціна, опис, переваги, контакти. Місця для заміни позначені `ЗАМІНИТИ` |
| `style.css` | Оформлення. Фірмові кольори задаються на початку файлу |
| `script.js` | Робота форми. На першому рядку вказана назва товару для повідомлень |
| `images/` | Фото. Зараз там ескізи, замініть їх справжніми фото (`.jpg`, `.png`, `.webp`) |
| `netlify/functions/order.mjs` | Функція на сервері: надсилає замовлення в Telegram і таблицю |
| `google-sheet-script.js` | Код для Google-таблиці (див. крок 5) |

## Крок 1. Створіть Telegram-бота (2 хв)

1. Відкрийте в Telegram **@BotFather** і надішліть йому `/newbot`.
2. Вкажіть ім'я (наприклад, «eurobubbleshop замовлення») і username, який закінчується на `bot`.
3. BotFather надішле **токен** вигляду `1234567890:AAH...`. Збережіть його і **нікому не показуйте**.

## Крок 2. Створіть групу для замовлень і дізнайтеся її ID (3 хв)

1. Створіть у Telegram групу, наприклад «Замовлення eurobubbleshop», і додайте туди менеджерів.
2. Додайте в групу свого бота як учасника.
3. Напишіть у групі будь-яке повідомлення, наприклад `привіт`.
4. Відкрийте в браузері адресу, підставивши свій токен:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
5. Знайдіть на сторінці `"chat":{"id":-100...`. Число з мінусом на початку — це **ID групи**. Скопіюйте його разом із мінусом.

> Якщо сторінка показує `"result":[]`, видаліть бота з групи, додайте ще раз, напишіть нове повідомлення й оновіть сторінку.
> Якщо пізніше змінити тип групи або налаштування історії, Telegram може змінити її ID. Тоді повторіть цей крок.

## Крок 3. Завантажте файли на GitHub (5 хв)

1. На [github.com](https://github.com) натисніть **+** → **New repository**, назва `eurobubbleshop`, і натисніть **Create repository**.
2. Натисніть **uploading an existing file**.
3. Перетягніть у вікно **всі файли та папки** проєкту.
4. Натисніть **Commit changes**.

> Перевірте, що на GitHub з'явився файл `netlify/functions/order.mjs`. Без нього замовлення не надсилатимуться.

## Крок 4. Підключіть Netlify (5 хв)

1. На [netlify.com](https://www.netlify.com) натисніть **Sign up** → **Sign up with GitHub**.
2. Натисніть **Add new project** → **Import an existing project** → **GitHub** і оберіть репозиторій `eurobubbleshop`.
3. Нічого не змінюйте і натисніть **Deploy**.
4. Відкрийте **Project configuration** → **Environment variables** і додайте змінні:

   | Назва | Значення |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен із кроку 1 |
   | `TELEGRAM_CHAT_ID` | ID групи з кроку 2 (з мінусом) |

5. **Project configuration** → **Change project name**: впишіть `eurobubbleshop`, і сайт буде доступний за адресою `eurobubbleshop.netlify.app`, якщо ця назва вільна.
6. Відкрийте **Deploys** → **Trigger deploy** → **Deploy project**, щоб сайт підхопив змінні.
7. Зробіть тестове замовлення. Воно має прийти в групу.

## Крок 5. Google-таблиця з копією замовлень (5 хв)

1. Створіть нову таблицю на [sheets.google.com](https://sheets.google.com), наприклад «Замовлення eurobubbleshop».
2. Відкрийте меню **Розширення** → **Apps Script**.
3. Видаліть код, який там є, і вставте вміст файлу `google-sheet-script.js`.
4. У рядку `const SECRET = "..."` впишіть **свій** довгий пароль. Змінюйте його тільки тут, а не у файлі на GitHub.
5. Натисніть 💾 **Зберегти**, потім **Розгорнути (Deploy)** → **Нове розгортання (New deployment)**:
   - ⚙️ Тип: **Вебзастосунок (Web app)**
   - Запуск від імені: **Я (Me)**
   - Хто має доступ: **Усі (Anyone)**
6. Натисніть **Розгорнути**, дозвольте доступ до свого акаунта і скопіюйте **URL вебзастосунку** (закінчується на `/exec`).
7. У Netlify додайте ще дві змінні:

   | Назва | Значення |
   |---|---|
   | `GOOGLE_SHEET_URL` | URL із пункту 6 |
   | `GOOGLE_SHEET_SECRET` | пароль із пункту 4 |

8. Знову виконайте **Trigger deploy** і зробіть тестове замовлення. У таблиці з'явиться рядок.

> Стовпець «Статус» можна використовувати для себе: змінюйте «Нове» на «Підтверджено», «Відправлено» тощо.
> Якщо Telegram тимчасово не відповідає, замовлення все одно збережеться в таблиці.

## Крок 6 (за бажанням). Meta Pixel для реклами

Якщо запускаєте рекламу в Instagram або Facebook:
1. У [Meta Events Manager](https://business.facebook.com/events_manager) створіть піксель і скопіюйте його ID.
2. У `index.html` знайдіть блок **Meta Pixel**, вставте ID замість `ВАШ_PIXEL_ID` і приберіть позначки коментаря навколо блоку.
3. Сайт сам повідомлятиме Meta про події: **InitiateCheckout** (клієнт відкрив форму) і **Lead** (клієнт відправив замовлення).

## Звідки прийшов клієнт

У кожному замовленні є рядок **📍 Джерело**. Сайт визначає його автоматично:
- з реклами Facebook/Instagram → «Реклама Facebook/Instagram»;
- з посилання в профілі Instagram → «Instagram»;
- з вашого посилання з міткою, наприклад
  `https://eurobubbleshop.netlify.app/?utm_source=instagram_stories` → «instagram_stories».

Додавайте різні мітки `?utm_source=...` до посилань у різних місцях (сторіс, профіль, Telegram-канал), і ви бачитимете, що приносить найбільше замовлень.

## Як змінювати сайт

Відкрийте файл на GitHub, натисніть ✏️ (Edit), внесіть зміни і натисніть **Commit changes**.
Netlify автоматично оновить сайт приблизно за 30 секунд.

**Як замінити фото:** завантажте свої фото в папку `images` на GitHub (**Add file** → **Upload files**),
а потім в `index.html` замініть назву старого файлу (наприклад, `images/bondplex-set.webp`) на назву свого, наприклад `images/photo1.jpg`.
